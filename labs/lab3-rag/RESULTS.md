## 2026-10-06 — 4단계 기준선 (BM25 만)

- 설정: parser=v1, chunk=section/600 (오버랩 없음, 맥락 주입), search=bm25(k1 1.5, b 0.75), tokenizer=어절+bigram, synonyms=off, rerank=off, k=3
- 코퍼스: 문서 37 · 청크 1,215 · k/청크 = 0.25% (1% 규칙 통과)
- 평가셋: 126문항 (정답 있음 121, 찾지 못함이 정답 5). 채점은 **문서 단위**
- **Recall@1 / Recall@3 / Recall@5 / MRR: 0.719 / 0.893 / 0.934 / 0.808**
- 절 단위 R@3 (정답 절이 있는 88문항): 0.693 — 문서는 맞혀도 다른 절을 가져오는 경우가 20%p

| 구분 | 문항 | R@1 | R@3 | MRR |
| --- | ---: | ---: | ---: | ---: |
| 퀴즈 원문 | 99 | 0.788 | **0.939** | 0.866 |
| 패러프레이즈 | 8 | 0.250 | **0.500** | 0.333 |
| 사내 문서 | 11 | 0.364 | 0.727 | 0.576 |
| 고객(공개 문서) | 3 | 1.000 | 1.000 | 1.000 |
| 형식: pdf (표) | 4 | 1.000 | 1.000 | 1.000 |
| 형식: docx | 3 | **0.000** | 0.667 | 0.389 |
| 함정: 약어 | 2 | 0.000 | **0.000** | 0.083 |
| 함정: 버전 모순 | 2 | **0.000** | 1.000 | 0.500 |
| 함정: 구어체 | 3 | 0.000 | 0.667 | 0.389 |

- 권한 누출: **0건** (전 126문항을 고객으로 검색, 상위 10개)
  - 실험: 1차 필터를 끄면(`--no-prefilter`) **67건**. 실제 API 에서는 RLS 가 원문 조회를 막고 "요청 n개 중 m개만 조회됨" 경고가 남는다
- 1등 BM25 점수: 맞힌 질문 14.1 ~ 105.6 (중앙 49.7) / 찾지 못함이 정답 11.5 ~ 32.2 (중앙 17.9) → **두 분포가 겹친다**

**해석**

1. **퀴즈 0.939 vs 패러프레이즈 0.500.** 퀴즈는 문서를 보며 써서 단어가 겹친다. 사용자처럼 자기 말로 물으면 절반을 놓친다. 1단계 "스스로 답해보기"의 답이 숫자로 나왔다. 전체 0.893 은 퀴즈 99문항이 끌어올린 숫자라 그대로 믿으면 안 된다
2. **버전 모순: R@3 는 1.0 인데 R@1 은 0.** "비밀번호 몇 달마다?" → 1등이 **폐지된 v4.1**(33.8), v4.2(30.4)는 2등. 검색은 찾았는데 순위가 틀렸다. 리랭커의 "최신 버전 가산·구버전 감점"이 고칠 곳 (5단계)
3. **약어: 0.** "MFA 꼭 써야 해?"에서 `mfa` 는 드문 단어라 가중치가 높지만 긴 청크에 한 번 나오면 4~6점뿐이다. "써야", "정확히" 같은 흔한 말이 여러 번 겹친 엉뚱한 청크가 더 많이 쌓는다. 정답 조항 제목은 "다중 인증"이라 약어도 없다 → 용어 사전 + 제목 일치 가산 (5단계)
4. **구어체·docx.** "결혼하면 돈 나와?" → 문서는 "경조금". "병원 때문에 두 시간만" → 1등이 온보딩 문서 `03-rag/retrieval-quality` 의 "실수 ①" 절. 그 절이 lab2 예시("두 시간만 자리를 비우고 싶습니다")를 인용하고 있어서다. **코퍼스끼리 표현이 겹치는 오염**
5. **PDF 표는 4/4.** 2단계에서 병합 머리글을 복원한 효과. 숫자와 "서울", "숙박비" 가 한 줄에 같이 있어서 키워드로도 잘 걸린다
6. **임계값.** 찾지 못함이 정답인 질문의 1등 점수(최대 32.2)가 맞힌 질문의 하위권(최소 14.1)보다 높다. BM25 점수 하나로 "찾지 못했어요"를 가르면 둘 중 하나는 틀린다 → 6단계에서 점수 + 질의어 적중률을 같이 본다

**다음에 손댈 곳 (5단계)**: R@3 는 높고 R@1 이 낮다 = 후보에는 있는데 순위가 틀렸다 → 리랭킹. 그리고 표현 차이(패러프레이즈·구어체·약어) → 용어 사전.
