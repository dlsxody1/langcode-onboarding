# 정보보안 정책 (v4.2, 2026-03 개정)

## 1. 계정 관리
- 모든 임직원은 개인 계정을 사용하며 계정 공유를 금지한다.
- 비밀번호는 12자 이상이며 90일마다 변경하여야 한다.
- 모든 사내 시스템은 다중인증(MFA)을 필수로 적용한다.

## 2. 데이터 분류
- 데이터는 공개, 내부, 기밀, 극비의 4단계로 분류한다.
- 기밀 등급 이상의 문서는 외부 반출이 금지되며, 반출이 필요한 경우 정보보호 책임자의 승인을 받아야 한다.
- 고객사로부터 수령한 데이터는 별도 계약이 없는 한 기밀 등급으로 취급한다.

## 3. 생성형 AI 사용
- 사내에서 승인된 AI 도구 외의 외부 AI 서비스에 회사 데이터를 입력하는 것을 금지한다.
- 승인 도구 목록은 정보보호팀이 분기별로 갱신한다.
- 고객사 데이터를 AI 도구에 입력할 때는 고객사와의 계약에 데이터 처리 조항이 있는지 먼저 확인하여야 한다.
- 소스코드는 승인된 AI 코딩 도구에 한하여 입력할 수 있다.

## 4. 단말 보안
- 업무용 노트북은 디스크 전체 암호화를 적용하여야 한다.
- 화면 잠금은 5분 이내로 설정한다.
- 분실 시 즉시 정보보호팀에 신고하여야 하며, 원격 삭제를 수행한다.

## 5. 외부 반출
- USB 등 이동식 저장매체 사용은 원칙적으로 금지한다.
- 파일 전송은 승인된 사내 시스템을 통해서만 수행한다.
